# btex-risk

**A fully configurable BTEX inhalation health-risk calculator** following the
[EPA RAGS Part F](https://semspub.epa.gov/src/document/HQ/140530) /
[RAIS](https://rais.ornl.gov) methodology, with Monte Carlo uncertainty analysis,
sensitivity analysis and publication-ready charts.

Feed it a CSV of measured benzene, toluene, ethylbenzene and xylene concentrations
(any mix of µg/m³, mg/m³, ng/m³, ppb, ppm), define your receptors in a YAML file, and get
hazard quotients, hazard indices, excess lifetime cancer risks, screening levels, probabilistic
distributions and a one-page dashboard.

<p align="center"><img src="docs/img/dashboard.png" width="100%" alt="Dashboard"></p>

> **The bundled dataset is synthetic.** `data/example_synthetic_btex.csv` was generated by
> `scripts/make_example_data.py` for demonstration only. It is not measured data.

## Methodology

Inhalation exposure is expressed as an **exposure concentration (EC)**, not as an inhaled dose
(RAGS Part F, EPA 2009, as implemented in RAIS):

| Quantity | Equation |
|---|---|
| Exposure concentration | `EC = CA × ET × EF × ED / AT`  (µg/m³) |
| Averaging time, non-cancer | `AT = ED × 365 × 24`  (h) |
| Averaging time, cancer | `AT = LT × 365 × 24`  (h), LT = 70 y |
| Hazard quotient | `HQ = EC / (RfC × 1000)` |
| Hazard index | `HI = Σ HQ`, also reported per target organ |
| Excess lifetime cancer risk | `ELCR = EC × IUR`  (one-hit, linear low-dose model) |

`CA` = air concentration (µg/m³), `ET` = exposure time (h/day), `EF` = exposure frequency
(days/year), `ED` = exposure duration (years), `RfC` in mg/m³, `IUR` in (µg/m³)⁻¹.

**Default RME receptors** (RAIS / RSL): *resident* (ET 24, EF 350, ED 26), *resident adult / child*
(ED 20 / 6), *composite worker* (ET 8, EF 250, ED 25). Any custom receptor can be added.

**Default toxicity values** (all overridable in the config):

| Compound | RfC (mg/m³) | IUR (µg/m³)⁻¹ | Critical effect group |
|---|---|---|---|
| Benzene | 0.03 | 7.8 × 10⁻⁶ | hematological / immune |
| Toluene | 5 | – | neurological |
| Ethylbenzene | 1 | 2.5 × 10⁻⁶ | developmental |
| Xylenes | 0.1 | – | neurological |

> Toxicity values are revised periodically. **Check them against the current RAIS / RSL tables
> before reporting results**, and override them under `toxicity.compounds` if they changed.

### Validation against EPA values

`tests/` back-calculates risk-based screening levels and compares them with the published
EPA Regional Screening Levels for benzene in air (TR = 10⁻⁶, THQ = 1):

| Receptor | Cancer SL (µg/m³) | EPA RSL | Non-cancer SL (µg/m³) | EPA RSL |
|---|---|---|---|---|
| Resident | 0.360 | 0.36 | 31.3 | ≈ 31 |
| Composite worker | 1.57 | 1.6 | 131 | ≈ 130 |

Hand-calculated EC / HQ / ELCR values, unit conversions, UCL logic, parsing and Monte Carlo
reproducibility are covered as well (`pytest`).

## Quick start

```bash
git clone https://github.com/https://github.com/Amin-Khademi-UT/btex-risk.git
cd btex-risk
pip install -r requirements.txt

python -m btex_risk run -c configs/default.yaml
```

Open `results/report.html` for the full report, or browse `results/figures/` and `results/tables/`.

Useful flags (they override the YAML):

```bash
python -m btex_risk run -c configs/default.yaml \
    --data my_data.csv --statistic mean --n-iter 50000 --seed 1 \
    --site "Pump island" --scenario worker --style light -o out/
python -m btex_risk run --no-plots        # tables only
python -m btex_risk run --no-mc           # deterministic only
```

From Python:

```python
from btex_risk import run
res = run("configs/default.yaml", overrides={"input": {"statistic": "mean"}})
res.agg            # HI and ELCR per site x scenario
res.mc_summary     # P5 / P50 / P95 and exceedance probabilities
```

## Input data

Long-format CSV, one row per sample:

| Column | Required | Notes |
|---|---|---|
| `site` | yes | any label |
| `compound` | yes | benzene, toluene, ethylbenzene, xylenes (aliases such as "Total Xylenes" work) |
| `concentration` | yes* | numeric |
| `unit` | no | `ug/m3`, `mg/m3`, `ng/m3`, `ppb`, `ppm` (default from config) |
| `sample_id` | no | |
| `nondetect`, `detection_limit` | no | non-detects are replaced by `nondetect_factor × DL` |

\* may be empty for non-detects. ppb/ppm are converted with the molar volume at the temperature and
pressure set in the config (24.465 L/mol at 25 °C, 101.325 kPa). The exposure-point concentration
(EPC) is the 95 % UCL of the mean (Student's t, capped at the maximum), or `mean`, `median`, `p95`,
`max`.

> For strongly skewed data, ProUCL-type UCLs are preferable; compute them externally and supply
> them as `max`/`mean` rows, or extend `summarize_epc`.

## Everything is configurable

`configs/default.yaml` is fully commented. Highlights:

```yaml
scenarios:
  resident: {preset: resident}
  gas_station_attendant:
    ET: {value: 10,  dist: triangular, min: 6,   mode: 10,  max: 12}
    EF: {value: 300, dist: triangular, min: 220, mode: 300, max: 340}
    ED: {value: 15,  dist: triangular, min: 1,   mode: 15,  max: 35}

toxicity:
  compounds:
    benzene: {iur: 2.2e-6}                              # override a value
    styrene: {mw: 104.15, rfc: 1.0}                     # add a compound

monte_carlo: {n_iter: 10000, concentration: {mode: mean_uncertainty, correlation: 0.3}}
sensitivity: {ranges: {ET: [6, 12]}}
plots: {style: dark, dpi: 200, formats: [png, svg, pdf]}
```

Parameter distributions: `fixed`, `uniform`, `triangular`, `normal`, `lognormal`
(optional `lower` / `upper` clipping). The `value` is the point estimate for the deterministic run.

## Monte Carlo and sensitivity: design notes

* One draw of ET / EF / ED per iteration is shared by all compounds (same person); compounds can be
  rank-correlated with a Gaussian copula (`correlation`).
* `mean_uncertainty` (default) samples the uncertainty of the long-term mean concentration, which is
  what chronic exposure depends on; `measurements` samples the spread of individual samples.
* The non-cancer HQ does not depend on ED, because AT = ED cancels it. The tornado chart shows this explicitly.
* One-at-a-time ranges: CA from the 95 % LCL of the mean to the maximum, ET/EF/ED from the P5–P95 of their
  distribution (or ± `variation`), LT / RfC / IUR ± `variation`.

## Limitations

* Chronic, inhalation-only screening-level assessment; no dermal or oral pathways, no acute or
  sub-chronic endpoints, and no age-dependent adjustment factors (none are applied to BTEX in RSL).
* Results are only as good as the concentration data (sampling design, detection limits, QA/QC).
* Not a substitute for a regulatory risk assessment.
